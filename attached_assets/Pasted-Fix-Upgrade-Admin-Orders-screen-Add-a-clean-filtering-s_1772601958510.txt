Fix & Upgrade Admin → Orders screen: Add a clean filtering system + search per tab (All / Delivery / Store Pickup) with a smooth, premium UX.

3) Sort dropdown (Newest, Oldest, Highest Amount, Lowest Amount).

1) Status chips (single-select):

1) Search behavior:
- Debounced search (300–500ms) to avoid spamming API.

2) Filters:
- Status filter should work with backend data model status field.

3) Sorting:
- Newest (default) = createdAt desc
- Oldest = createdAt asc
- Highest Amount = total desc
- Lowest Amount = total asc

- status: all | pending | confirmed | ready_for_pickup | picked_up | delivered | cancelled
- q: search string
- dateFrom/dateTo: ISO yyyy-mm-dd or ISO datetime
- sort: newest | oldest | total_desc | total_asc
